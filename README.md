# By Harper Clothing

Shopify front-end project built with Liquid, JavaScript, HTML and CSS.

Live website: https://byharperclothing.com

## About the project

By Harper Clothing is a Shopify store I worked on as a front-end developer.

I worked on the theme and storefront using Liquid, JavaScript, HTML and CSS. The project includes custom Shopify sections, product components and responsive layouts for the different parts of the store.

## What I worked on

Custom Liquid sections  
Product cards  
Color swatches  
Cart drawer  
FAQ sections  
Customer review sections  
Look sections  
New product sections  
Brand sections  
Responsive layouts  
JavaScript interactions

## Technologies

Liquid  
JavaScript  
HTML5  
CSS3  
Shopify

## Some of the components

The theme includes custom `harper-*` sections and components for products, navigation, cart, reviews, FAQ, looks, brands and other storefront content.

This repository presents part of my work on the project. Production files and store configuration are not included.
